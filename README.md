# FWD Premium Financing Illustration App

Professional illustration tool for FWD Wealth ICON Horizon (WIH) and Wealth ICON Supreme III (WIS3) with premium financing scenarios.

## Tech Stack

- React 18
- Vite 5
- Recharts

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build

```bash
npm run build
```

Output is in `dist/` folder.

## Deployment

Auto-deployed to Vercel on `git push` to `main` branch.
